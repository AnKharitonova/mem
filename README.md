# Мемы, которые не вошли в резюме

Адаптивный мини-сайт в пастельной скетчбук-стилистике. Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите `index.html` и папку `assets` в корень репозитория. Включены фильтры, просмотр мемов крупнее и кнопки копирования подписей. Подписи можно менять в массиве `memes` внутри `index.html`.
